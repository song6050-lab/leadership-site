# 사이트 설계도(PRD) — (사이트 이름 미정)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
기업 HRD 담당자가 리더십·조직 교육 강사의 프로그램과 레퍼런스를 확인하고, 출강·컨설팅을 문의하거나 공개강좌를 신청하는 사이트.

## 2. 손님
- 누가: 기업 HRD(교육·인사) 담당자 — 사내 리더십·조직 교육을 맡길 강사를 찾는 사람
- 어디서 알고 오나: 지인·기존 고객 소개, 블로그·링크드인

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 강의 프로그램·커리큘럼 (어떤 주제를, 몇 시간, 어떤 방식으로)
2. 레퍼런스 — 어느 기업·기관에서 진행했는지
3. 강사 경력·전문성

## 4. 믿게 할 증거 (실제로 있는 것만)
- 진행한 기업·기관 목록: (미정 — 사이트에 공개해도 되는 이름만 사용자가 직접 채움)
- 경력·자격·저서: (미정 — 사용자가 직접 채움)
- 강의 현장 사진: 준비 중
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 교육 문의하기 (보조 버튼: 공개강좌 신청)
- 누르면: 문의 폼 (폼 안에서 '기업 교육·컨설팅 문의 / 공개강좌 신청' 중 선택)

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + 버튼 (교육 문의하기 / 공개강좌 신청)
2. 강의·컨설팅 프로그램 — 주제별 카드 (대상·시간·방식)
3. 레퍼런스 — 진행 기업·기관 목록
4. 강사 소개 — 경력·자격·저서
5. 공개강좌 안내 — 다음 일정·장소·신청 버튼
6. 후기 자리 (비워 둠)
7. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 구분: 기업 교육·컨설팅 문의 / 공개강좌 신청
- 회사명(소속)
- 문의 내용 (자유롭게)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정 — 기업 출강은 "문의 시 안내"로 둘지 결정 필요, 공개강좌 수강료 미정)
- 시간: (미정 — 공개강좌 날짜·시간)
- 위치: (미정 — 공개강좌 장소)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 결제 (공개강좌 수강료 온라인 결제)
- 회원가입·로그인
- 알림 메일
- 블로그·칼럼 게시판
- 사진 올리기 기능

## 10. 첫 화면 한 문장 후보
1. 리더가 바뀌면 조직이 움직입니다 — 현장에서 검증된 리더십·조직 교육
2. 우리 회사에 맞는 리더십 교육, 설계부터 진행까지 함께합니다
3. 팀장 한 사람의 변화가 팀 전체의 성과로 이어지도록

## 11. 다음에 할 것
- 진행 기업 목록·경력·저서 내용 채우기
- 공개강좌 일정·장소·수강료 확정 후 넣기
- 강의 현장 사진, 실제 후기 모이면 추가
- 사이트 이름 정하기
- (필요하면) 공개강좌 온라인 결제, 신청 알림 메일

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 → 사용자가 준 디자인 기준(Modern Atmospheric: 짙은 슬레이트 배경 #0f172a, 인디고 #6366f1, 유리 패널, Lora·Inter·Space Grotesk 글꼴)으로 바꿈 (2026-10-17)
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin (문의/공개강좌 신청을 구분해서 보기)
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
